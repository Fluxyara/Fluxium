Get started

Install in four steps

No installer and no admin rights. Fluxium runs from the folder you extract.

  1. Download

    Press the download button at the top of this page and save the zip.

  2. Extract

    Right-click the zip and choose Extract All. Put the folder somewhere permanent, like Documents.

  3. Run

    Open the folder and double-click Flux's Games Hub.exe. That is Fluxium, named after its maker.

  4. Create your account

    Make a username and password, then browse the library. Updates install on their own from here.

Windows may show a blue warning the first time

Fluxium is a small private project and is not code-signed yet, so Windows SmartScreen can say it does not recognise the app. Click More info, then Run anyway. Only do this for a copy you got from the person who shared this page with you.

Your account and your privacy

  • Accounts live on the host's server. Nothing about other people's accounts is stored on your PC.
  • Passwords are not kept in plain text. The server stores a salted hash, and replies from the server are signed so the app can tell they are real.
  • Only the host can manage the library. Uploading, editing, moderating and updating are host-only tools.
Questions

Frequently asked

Do I need an account?

Yes. The first time you open Fluxium you create a username and password. The same login works every time you open the app.

Why is the library empty or the app says it cannot connect?

Fluxium talks to the host's server, which runs on the host's own computer. If that computer is off, the app cannot load the library. Try again later or ask the person who shared Fluxium with you.

How do updates work?

Every time you open Fluxium it checks for a newer version. If there is one, a progress window appears, the app restarts and you are on the latest version. You can turn this off in Settings.

Can I move the folder after extracting it?

Yes, as long as you close Fluxium first. Your account lives on the server, so it is not tied to the folder.

A download stopped halfway. What now?

Open the Downloads tab and press Resume. If you closed the app mid-download, Fluxium continues it from where it stopped the next time you open it.

I forgot my password.

Ask the host. They can reset your password from the Users tab, and you can then choose a new one in Settings.

Does it work on Mac, Linux or phones?

Not right now. Fluxium is built for 64-bit Windows 10 and 11.
